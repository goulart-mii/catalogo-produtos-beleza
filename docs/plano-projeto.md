# Plano do Projeto

## Equipe

Camily Vitória de Souza Goulart – Desenvolvimento individual do projeto.

## Recursos

VS Code, HTML, CSS, PHP, MySQL, XAMPP e GitHub.

## Acompanhamento

Utilizar o GitHub para organizar e acompanhar as atividades do projeto, definir prazos para cada etapa, testar as funcionalidades após o desenvolvimento e registrar as alterações realizadas no repositório.

## Riscos e ações preventivas

Perda de dados: realizar backups periódicos do banco de dados.

Produtos com disponibilidade incorreta: atualizar frequentemente o status dos produtos.

Sistema inoperável por falta de manutenção: realizar manutenção preventiva e testes periódicos.
